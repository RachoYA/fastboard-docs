# Сортировка по форматированному виду даты | Документация Fastboard

Source: https://help.fastboard.online/user/primery-i-gaidy/sortirovka-po-formatirovannomu-vidu-daty/


## **Задача**[​](#задача)

Вывести данные в историческом порядке, но отобразить дату в произвольном, удобном для пользователя формате (например, "**17.02 (Вт)**", "**17.02.26**").


### **Проблема**[​](#проблема)

Если просто преобразовать поле с датой в строку нужного формата и использовать её как разрез, сортировка по этому полю будет алфавитной (лексикографической), а не хронологической. В результате 04.12.15 идет до 08.05.15, а не в правильной последовательности.

![Если просто преобразовать поле с датой в строку нужного формата и использовать её как разрез, со](https://book.winsolutions.ru/uploads/images/gallery/2026-04/embedded-image-1rpuukg3.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2026-04/embedded-image-1rpuukg3.png)):
> 2,000  
> 0  
> 01.03.15  04.12.15  08.05.15  11.05.15  14.04.15  17.07.15  20.11.15  24.01.15  27.02.15  30.07.15  
> Скриншот показывает столбчатую диаграмму с временными метками на оси X и значениями до 2,000 на оси Y, вероятно, отражающую динамику какого-либо показателя за период с марта 2015 по июль 2015 года.



### **Решение**[​](#решение)

- В качестве разреза будем использовать отформатированную дату
![В качестве разреза будем использовать отформатированную дату](https://book.winsolutions.ru/uploads/images/gallery/2026-04/embedded-image-hbeeg8n5.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2026-04/embedded-image-hbeeg8n5.png)):
> 1) `formatDateTime (Sample_Superstore.Order_Date, '%d.%m.%y')`  
> 2) Скриншот показывает формулу форматирования даты в BI-платформе Fastboard.


- Добавим группировку и сортировку по полю даты с той же агрегацией. Сейчас агрегируем по днем и подойдет изначальное поле даты.
![Добавим группировку и сортировку по полю даты с той же агрегацией. Сейчас агрегируем по днем и п](https://book.winsolutions.ru/uploads/images/gallery/2026-04/embedded-image-yizkdnoa.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2026-04/embedded-image-yizkdnoa.png)):
> 1)  
> GROUP BY  
> Sample_Superstore.Order_Date  
> ORDER BY  
> Sample_Superstore.Order_Date  
> 2) Скриншот показывает фрагмент SQL-запроса с группировкой и сортировкой по полю Order_Date из таблицы Sample_Superstore.


При агрегации по месяцам (вывод названия месяца) тогда можно использовать id месяца для группировки и сортировки


### Итог[​](#итог)

Красивые подписи дат на графике, при этом сами данные отсортированы в правильном хронологическом порядке.

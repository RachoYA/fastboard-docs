# Раздел «Публикации» проектов | Документация Fastboard

Source: https://help.fastboard.online/user/administrirovanie/razdel-publikacii/

Раздел "Публикации" предназначен **для централизованного контроля** всех публикаций. Ранее мы рассмотрели пошагово как опубликовать проект, с подробной инструкцией о публикации проекта можно ознакомиться по ссылке.

**В разделе "Публикации"** вы увидите:

- **Строка для быстрого поиска** опубликованного проекта
- **Список** всех опубликованных проектов **по названию**
- **Список** всех опубликованных проектов **по потоку**
- Информацию об **авторе** публикации
- Информацию о **дате и времени** публикации

> Список опубликованных проектов в BI-платформе Fastboard с указанием имени проекта, потока, автора и даты публикации.


Кликнув на название проекта в колонке "Проект", **вы откроете его в новой вкладке браузера**.

Рядом с названием каждого проекта находится кнопка в форме карандаша, с помощью которой вы можете **редактировать фреймы** опубликованных дашбордов (отчётов) или **удалить публикацию**, нажав на иконку корзины.

Для **сортировки** списка проектов по дате воспользуйтесь маленьким треугольником рядом с заголовком колонки "Дата публикации".

Кроме того, вы можете **опубликовать проект**, не переходя на главную страницу: выберите нужный поток и проект из выпадающего списка и следуйте стандартному процессу настройки публикации.

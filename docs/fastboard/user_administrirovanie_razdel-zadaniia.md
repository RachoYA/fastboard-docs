## **Создание задания**[​](#создание-задания)

Для создания нового задания выполните следующие шаги:

- Нажмите **кнопку «Создать»** в правом верхнем углу страницы для открытия модального окна.
- **Выберите поток и проект**, для которого необходимо создать задание.
- Убедитесь, что ползунок **«Активно»** включен для выполнения задания (также может быть использован для временного отключения выполнения)
- Определите **расписание** запуска в минутах или в [формате CRON](https://help.fastboard.online/user/administrirovanie/spravocnye-materialy/sintaksis-zadanii-dlia-cron/).
- Подтвердите создание задания нажатием **кнопки «Создать»**.

## **Настройки импорта для многопоточной загрузки**[​](#настройки-импорта-для-многопоточной-загрузки)

Импорт для многопоточной загрузки — это процесс переноса данных, при котором обработка разных таблиц или частей данных идёт параллельно в нескольких потоках. Это нужно, чтобы существенно ускорить загрузку больших объёмов информации и эффективнее использовать вычислительные ресурсы системы.

Нажмите «Настройки импорта» (находится в модальном окне создания задания, рядом с кнопками «Отмена» и «Создать»).

В открывшемся окне «Настройки импорта» отметьте галочками таблицы, для которых нужна многопоточная загрузка (неподходящие таблицы выбрать нельзя).

Для каждой подходящей таблицы проверьте, какой столбец указан в списке «Столбцы для разделения» — если система уже подобрала подходящий, менять не нужно; если нет — выберите нужный столбец из списка.

При необходимости включите опцию «Выполнять полную проверку столбцов при запуске» (учтите, что это увеличит время запуска скрипта). Если нужно быстро включить/выключить загрузку сразу для всех таблиц одного источника — используйте общий чекбокс у заголовка источника.

Когда все настройки выставлены, нажмите кнопку «Сохранить».

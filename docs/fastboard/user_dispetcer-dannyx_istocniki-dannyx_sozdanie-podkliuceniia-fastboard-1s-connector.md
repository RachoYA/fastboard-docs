# Создание подключения «FastBoard 1С Connector» | Документация Fastboard

Source: https://help.fastboard.online/user/dispetcer-dannyx/istocniki-dannyx/sozdanie-podkliuceniia-fastboard-1s-connector/

**Коннектор (подключение к данным) к Denvic** — это возможность создавать базы данных и выгружать в них данные из экстрактора Denvic напрямую в Fastboard. А далее работать с этими БД как с любыми другими источниками данных и использовать их в своих проектах. В Fastboard настраиваются специальный выделенный порт и адрес, к которому может подключиться только Denvic.

Подключение настраивается на стороне экстрактора, с использованием учетной записи Fastboard. Рассмотрим подробнее:

В форме подключения укажите следующие настройки:

флаг «**Партиции в нижнем регистре**» рекомендуем оставить включенной, (это важно для чувствительных к регистру СУБД).

Заполните параметры подключения:

- **Портал** — формат ссылки вида `https://fastboard-front-dev.fb-dev.winsolutions.ru/`;
- **Логин** — данные пользователя;
- **Пароль** — данные пользователя;
- **Имя базы** — название коннектора в FastBoard, *например FastBoard demo*.
Заполните дополнительные настройки:

- **Таймаут** (обычно это 30-60 секунд);
- Настройка **«Ограничение идентификаторов»** отвечает за ограничение размера имени полей таблиц. (по умолчанию, 200 символов в URL (веб-адрес) кодировке).
- флаг «**Не сжимать данные**» следует установить, если необходимо отключить сжатие данных для Clickhouse (как для файла данных, так и для запроса). Если сжатие не отключено, то запросы короче 1024, как и раньше, не сжимаются.
Далее, нажмите кнопку «Проверить подключение». Если будут на каком то из шагов ошибки, то:

- убедитесь, что у расширения «Экстрактор 1С» снят флаг «Безопасный режим»;
- Далее, идите к вашим системным администраторам, возможно есть проблемы с доступами.
Нажмите «Записать и закрыть».

### **Подключение коннектора 1С Connector в Fastboard**[​](#подключение-коннектора-1с-connector-в-fastboard)

Для работы с выгруженными из Denvic базами данных необходимо выполнить подключение в Fastboard.

В интерфейсе Fastboard откройте **Диспетчер данных** и в поле поиска укажите название коннектора: **FastBoard BI demo**. Коннектор всегда доступен именно под этим именем.

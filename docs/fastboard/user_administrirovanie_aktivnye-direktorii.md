# Активные директории (LDAP) | Документация Fastboard

Source: https://help.fastboard.online/user/administrirovanie/aktivnye-direktorii/

**Активные директории** — это система управления, которая используется для хранения информации о пользователях, проектах и других ресурсах. Она помогает администраторам организовывать и управлять доступом к этим ресурсам.

Данная вкладка предоставляет возможность **создать** подключения к доступным доменам для импорта пользователей и групп. Для обновления статуса предусмотрена кнопка **«Обновить»**. Импортированные пользователи и группы могут иметь такие же права и роли, как и локальные, после получения соответствующих лицензий и доступов.

Кликнув на строку с нужным названием диектории, ниже станут доступны вкладки:

- **Детали** (Проект, ID проекта, График запуска обновлений и текущий статус);
- **Пользователи** (Группы и пользователи относящиеся к выбранной директории)
- **Тенанты**
Кроме того, **сменить тенант** можно через выпадающий список вверхну справа, рядом с иконкой пользователя.

## **Создание подключения**[​](#создание-подключения)

**Название подключения:** Отображаемое имя в таблице подключений.

**URL:** Адрес, откуда будут импортированы пользователи.

**Авторизация**. Это учетные данные для подключения к домену

**Фильтры импорта (для опытных пользователей):**

- Домен или домены через запятую
- Имена пользователей
- Имена групп
**Регулярная синхронизация.** Активируйте флаг для периодической синхронизации списка пользователей. График синхронизации описывается строкой задания в [синтаксисе CRON](https://users-docs-dev.fb-dev.winsolutions.ru/gostech/administrirovanie/spravocnye-materialy/sintaksis-zadanii-dlia-cron/)

**Добавление новых пользователей:** Если флаг неактивен, при последующих синхронизациях количество пользователей не изменится. Будет выполнен разовый импорт, после чего пользователи будут только обновляться.

Подтвердите создание подключением нажатием кнопки **«Создать»**. Подключение появится в таблице и сразу запустится.

**Редактирование подключения** производится аналогично созданию: измените необходимые параметры, нажав на карандашик ![image 2.png](https://book.winsolutions.ru/uploads/images/gallery/2025-12/scaled-1680-/image-2.png), и сохраните изменения.


## **После импорта**[​](#после-импорта)

После успешного завершения импорта на вкладке «Пользователи» будет отображен список всех импортированных пользователей и групп. После выдачи ролей и доступов они смогут полноценно использовать систему.

![Frame 326.png](https://book.winsolutions.ru/uploads/images/gallery/2026-07/scaled-1680-/frame-326.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2026-07/scaled-1680-/frame-326.png)):
> Детали Пользователи Тенанты

> Скриншот показывает вкладку «Пользователи» в интерфейсе управления пользователями и группами BI-платформы Fastboard, с возможностью синхронизации и отображением группы для директории winsolutions.ru.


При удалении подключения все импортированные пользователи будут также удалены из системы.

## **Задача**[​](#задача)

Построить круговую диаграмму на основе нескольких разных метрик (показателей), например:

- «Переходы»
- «Добавления в корзину»
- «Покупки»

## **Проблема**[​](#проблема)

Стандартная логика BI-визуализаций требует для таких графиков одну размерность (разрез — названия этапов) и одно числовое поле (значения). Нельзя просто перетащить три разных показателя в конструктор воронки.


## **Решение**[​](#решение)

Для обхода ограничения используется эмуляция разреза через функцию arrayJoin и конструкция CASE

- Создается вычисляемое поле **Разрез**, которое содержит список названий шагов воронки
![Снимок экрана 2026-07-22 в 01.14.28.png](https://book.winsolutions.ru/uploads/images/gallery/2026-07/scaled-1680-/snimok-ekrana-2026-07-22-v-01-14-28.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2026-07/scaled-1680-/snimok-ekrana-2026-07-22-v-01-14-28.png)):
> SELECT  
> Выражение для разрезов  
> 1 arrayJoin (  
> 2   array (  
> 3     'Посетители',  
> 4     'Регистрации',  
> 5     'Уникальные участники',  
> 6     'Сертификаты'  
> 7   )  
> 8 ) AS dim  
> Скриншот показывает SQL-выражение в BI-платформе Fastboard, которое формирует массив строк и преобразует его в отдельные строки с помощью функции arrayJoin, присваивая результату псевдоним dim.


- Создается вычисляемое поле **Значение**, которое анализирует текущий элемент разреза и подставляет нужную формулу (для простоты возьмем фиксированное значение). Логика реализуется через **CASE WHEN**
![Снимок экрана 2026-07-22 в 01.13.32.png](https://book.winsolutions.ru/uploads/images/gallery/2026-07/scaled-1680-/snimok-ekrana-2026-07-22-v-01-13-32.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2026-07/scaled-1680-/snimok-ekrana-2026-07-22-v-01-13-32.png)):
> Выражение для показателей  
> 1 CASE  
> 2 WHEN dim = 'Продажи' THEN 100  
> 3 WHEN dim = 'Заказы' THEN 75  
> 4 WHEN dim = 'Клиенты' THEN 50  
> 5 WHEN dim = 'Отказы' THEN 25  
> 6 END AS "Показатель"  
> Скриншот показывает SQL-выражение CASE для вычисления показателя в зависимости от значения поля dim.


- Для воронки **важен** **порядок**. Чтобы задать правильную последовательность шагов, можно добавить произвольную сортировку
![Снимок экрана 2026-07-22 в 01.18.19.png](https://book.winsolutions.ru/uploads/images/gallery/2026-07/scaled-1680-/snimok-ekrana-2026-07-22-v-01-18-19.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2026-07/scaled-1680-/snimok-ekrana-2026-07-22-v-01-18-19.png)):
> 1)  
> order by  
> indexOf(  
>     array(  
>         'Посетители',  
>         'Регистрации',

>         'Сертификаты'

>     dim  
> )  
> 2) Скриншот показывает фрагмент SQL-запроса с функцией indexOf для сортировки по заданному порядку категорий на русском языке.


Также, можно задать сортировку по рассчитанному показателю

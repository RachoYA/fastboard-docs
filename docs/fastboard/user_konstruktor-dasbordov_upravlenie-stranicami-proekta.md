## **Боковая панель (левая часть интерфейса)**[​](#боковая-панель-левая-часть-интерфейса)

Переход в эту панель осуществляется через вкладку "Страницы", значок Листа ![Снимок экрана 2026-01-30 в 01.51.45 1.png](https://book.winsolutions.ru/uploads/images/gallery/2026-01/scaled-1680-/snimok-ekrana-2026-01-30-v-01-51-45-1.png) Удобна для управления всеми страницами текущего дашборда. Здесь можно:

- **Создать** страницу
- **Импортировать/экспортировать** страницы. При наличии экспортированного файла — позволяет быстро перенести уже созданную страницу в другой проект.
- **Удалить** страницу
- **Переименовать**
- **Скрыть/отобразить** скрытую страницу. Скрытые страницы видны только разработчику.
- **Дублировать** страницу
- **Ограничить** доступ

> Удалить  
> 2) Скриншот показывает интерфейс управления страницами в BI-платформе Fastboard с контекстным меню для редактирования страницы.

### **Панель настроек страницы (правая часть интерфейса)**[​](#панель-настроек-страницы-правая-часть-интерфейса)

Вкладка появится при клике на **свободную область страницы**(вне визуальных компонентов). Включает следующие параметры:

- Размер страницы.
- Показать границы страницы.
- Изменить цвет страницы.
- Изображение.
- Триггеры страницы.

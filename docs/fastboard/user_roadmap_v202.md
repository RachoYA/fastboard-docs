## Багфикс[​](#багфикс)

- Устранено пропадание визуализаций со страницы проекта
- Исправлено некорректное сохранение последовательности элементов при экспорте в XLSX (теперь соответствует визуализации)
- Устранено закрашивание виджетов серым цветом при фильтрации
- Исправлена «Внутренняя ошибка» при переключении между вариантами загрузки изображения в Медиа-блоке
- Устранено сохранение размытия контейнера после отключения заливки фона
- Убрана лишняя полоса прокрутки в секциях SQL-редактора виджета высотой в 3 строки
- Исправлено раскрытие списка выбора тенантов в менеджере проектов
- Устранён выход кнопок формы за её границы при подгрузке данных скроллом (Диспетчер данных, файловый коннектор)

### Доработки по MSSQL[​](#доработки-по-mssql)

- Добавлена возможность разбивать данные на части
- Переписан импорт: синхронизация теперь выполняется через errgroup
- Добавлены экспериментальные функции: прогрев кэша и получение данных в формате JSON
- Добавлено детальное логирование (origin_read, next, scan)
- Отключён алгоритм Nagle's algorithm
- Увеличен packet size до 32767

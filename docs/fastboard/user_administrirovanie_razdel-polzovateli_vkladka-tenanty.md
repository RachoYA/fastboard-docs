# Пользователь: вкладка «Тенанты» | Документация Fastboard

Source: https://help.fastboard.online/user/administrirovanie/razdel-polzovateli/vkladka-tenanty/

Вкладка предназначена для администрирования пользователей и их распределения по тенантам (организациям).

Интерфейс вкладки состоит из двух основных областей:

- **Область поиска по пользователям** (расположена слева). Здесь отображается список всех пользователей.
- **Рабочая область** (расположена в центре). Здесь отобажается список тенантов, в которых пользователь состоит

## Добавление пользователя в тенант[​](#добавление-пользователя-в-тенант)

В списке слева **найдите пользовател**я и кликните на него

Кликните кнопку **«Добавить»** и выберите нужные тенанты из выпадающего списка (возможно одновременное добавление в несколько тенантов) и подтвердить выбор повторным нажатием кнопки «Добавить»

![Кликните кнопку «Добавить» и выберите нужные тенанты из выпадающего списка (возможно одновременн](https://help.fastboard.online/assets/images/frame-278-1c7b19a6dc00949b5c6581646d486697.png)

Далее, в таблице в колонке «Лицензии» установите отметку (галочку) напротив новых выбранных тенантов и нажмите кнопку «Сохранить» для фиксации изменений

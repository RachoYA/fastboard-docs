# Фильтр «Кнопки» | Документация Fastboard

Source: https://help.fastboard.online/user/biblioteka-widgetov/vse-diagr/filtr-knopki/

Представляет собой одну (или несколько) кнопку, нажатие на которую отфильтрует весь лист по ее значению. Может быть выбрано не более одного значения. Выбор значения происходит по клику на один из элементов фильтра. Если сохранить лист с активным фильтром, фильтрация будет активна при следующем открытии листа.

## Основные настройки[​](#основные-настройки)


### **[Параметры контейнера](https://users-docs-dev.fb-dev.winsolutions.ru/konstruktor-dasbordov/parametry-vidzeta/#%D0%BF%D0%BE%D0%BA%D0%B0%D0%B7%D0%B0%D1%82%D0%B5%D0%BB%D0%B8)**[​](#параметры-контейнера)


#### **Реальные данные**[​](#реальные-данные)

Скрыть/показать данные из модели. Пока отключена глобальная настройка, управляющая показом данных каждый визуальный компонент может быть настроен в отдельности. По умолчанию отключено. [Подробнее о виртуальных данных](https://users-docs-dev.fb-dev.winsolutions.ru/konstruktor-dasbordov/virtualnye-dannye/)


#### **Модель данных**[​](#модель-данных)

Позволяет выбрать одну из моделей данных, ранее созданных в конструкторе моделей данных. Данные из этой модели будут использоваться для данного визуального компонента (построение графика, заполнение полей таблицы, получение значений для фильтрации и т.д.)


#### **Применить ко всем листам**[​](#применить-ко-всем-листам)

Данная настройка позволяет применить выбранные фильтры ко всем листам приложения


#### **Элементы фильтра**[​](#элементы-фильтра)

Для построения необходимо выбрать столбец (столбцы) из импортированных данных. Количество столбцов будет равно количеству кнопок фильтра. Напротив имени каждого столбца отображается количество значений, которое в нем содержится. ![Напротив имени каждого столбца отображается количество значений, которое в нем содержится.](https://book.winsolutions.ru/uploads/images/gallery/2023-06/scaled-1680-/image-1686941663558.png)

#### **Позиционирование**[​](#позиционирование)

Данная настройка позволяет располагать фильтры в границах контейнера по левому краю/по центру/по правому краю.


#### **Инвертация фильтра**[​](#инвертация-фильтра)

Переключатель инвертации фильтров находится во вкладке "События" в фильтрах

![Frame 282.png](https://book.winsolutions.ru/uploads/images/gallery/2026-04/scaled-1680-/frame-282.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2026-04/scaled-1680-/frame-282.png)):
> События  
> Управление триггерами  
> Управление видимостью  
> Влияние на виджеты  
> Не прекращать фильтрацию  
> Скрыть в панели выборки  
> Инвертировать фильтр  
> Скриншот показывает меню настроек событий в BI-платформе Fastboard с переключателями управления триггерами, видимостью, влиянием на виджеты, фильтрацией и скрытием в панели выборки, а также выделенным пунктом «Инвертировать фильтр».


В инвертированном режиме при выборе значения в фильтре это значение будет исключено из разрезов всех визуальных элементов, на которые влияет этот фильтр. То есть, фильтр **будет показывать не совпадающие с критерием элементы, а все остальные, те, которые не соответствуют.**

> 2) Скриншот показывает интерфейс BI-платформы Fastboard с открытым проектом «Тестовый макет», включая навигацию по тенантам, список проектов и панель информации о проекте.


**Навигация по потокам**: Этот раздел позволяет пользователю просматривать доступные потоки. В отличие от аналогичного раздела "Менеджер проектов", здесь отсутствуют "Черновики". Тут вы можете создать поток Нажатием по кнопке **«Создать поток»** в левом нижнем углу экрана вызывается модальное окно для ввода названия. После нажатия на кнопку «Ок» новый поток появляется в списке доступных пользователю.

Также, вы можете **удалить поток**, нажав на иконку корзины, которая появляется при наведении курсора на поток.

**Центральный блок**: В этом блоке отображается название текущего потока, а также **список проектов этого потока**. Для быстрого поиска проекта есть поисковая строка по названию. Дополнительно карточки проектов можно отсортировать в порядке возрастания или убывания по алфавиту или дате создания/изменения.

**Правое выпадающее меню:** Это меню предлагает функции для изменения интерфейса, **выхода из учетной записи** и перехода в панель **"Менеджер проектов"**. Также в этом меню находится раздел **"Помощь"**, где размещены ссылки на текущее руководство, руководство для администраторов и новости о релизах.

**Правая боковая панель**:

- **Описание проекта.** Поле для ввода информации/заметок по проекту.
- **Инфо** содержит название, ID проекта, даты создания и последнего изменения, дата обновления данных, кнопка выбора обложки и поле для описания проекта. При нажатии на кнопку выбора обложки открывается окно для выбора изображения с устройства в формате png или jpeg. При клике на поле для описания проекта, появится курсор. Дополнительной кнопки для сохранения текста или обложки нет, все изменения сразу фиксируются и сохраняются.
- **Версии** содержат список точек сохранения проекта и возможность откатить проект к одной из них
При клике правой кнопкой мыши по проекту выпадает меню доступных действий:

- Копировать (в другой поток)
- Переместить (в другой поток)
- Откатить (к предыдущей версии)
- Защитить
- Переименовать
- Изменить статус
- О проекте
- Удалить
- Экспортировать проект
- Опубликовать (общедоступно)

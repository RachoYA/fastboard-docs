# Экспорт дашборда в JPEG | Документация Fastboard

Source: https://help.fastboard.online/user/primery-i-gaidy/eksport-dasborda-v-jpeg/


## **Задача**[​](#задача)

Сохранить **страницу дашборда** для дальнейшего использования в презентациях.


## **Проблема**[​](#проблема)

Страница дашборда **может быть большого размера**, что вызовет проблему создания снимка. Также снимок экрана будет захватывать лишнюю информацию.


## **Решение**[​](#решение)

Использование **функционала экспорта** дашборда

- Выбираем интересующий нас лист и нажимаем **правую клавишу мыши.**
![Выбираем интересующий нас лист и нажимаем правую клавишу мыши.](https://book.winsolutions.ru/uploads/images/gallery/2026-04/embedded-image-fuuoisvn.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2026-04/embedded-image-fuuoisvn.png)):
> Основная Детализация + ← → 🗑️ 👁️ ↑ ↓  
> Скриншот показывает панель вкладок с активной вкладкой «Детализация» и набором инструментов для навигации, копирования, удаления, просмотра, загрузки и скачивания данных.


- Выбрав экспорт появится **всплывающее окно** с выбором формата снимка.
![Выбрав экспорт появится всплывающее окно с выбором формата снимка.](https://book.winsolutions.ru/uploads/images/gallery/2026-04/embedded-image-lxnel0z9.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2026-04/embedded-image-lxnel0z9.png)):
> Экспорт страниц  
> Выберите формат экспорта  
> Снимок (JPG)  
> Файл (JSON)  
> Отмена  
> Продолжить  
> Скриншот показывает диалоговое окно выбора формата экспорта страниц в BI-платформе Fastboard.


- Нас интересует **JPG** формат для сохранения снимка. После выбора формата нажимаем **“Продолжить”** и выбираем папку и название для сохранения.

## **Итог**[​](#итог)

Сохранили снимок страницы проекта для дальнейшего использования

# Стратегия цвета визуализаций | Документация Fastboard

Source: https://help.fastboard.online/user/konstruktor-dasbordov/strategiia-cveta/

В Fastboard предусмотрены две стратегии автоматического назначения цветов: **по разрезам** и **по показателям**. Они обеспечивают единообразие цветовой логики в визуализациях, содержащих несколько разрезов или показателей.


## **Стратегия по разрезам**[​](#стратегия-по-разрезам)

**Навигация:** Выбрать визуализацию — вкладка "Вид" — "Оформление точек данных".

Применяет выбранную **группу цветов** ко всем разрезам визуализации (эквивалентно ручному выбору одной и той же цветовой группы на вкладке **«Данные»**).

### **Правила применения**[​](#правила-применения)

- Любые цветовые правила — **SQL-цвет**, **цвет по значению**, пользовательские правила — при активной стратегии применяются **одновременно ко всем разрезам или ко всем показателям**.
Можно выбрать либо стратегию по разрезам, либо по показателям. Две стратегии одновременно не поддерживаются.

- Если для элемента задан **локальный цвет**, он **перекрывает** стратегию цвета. Это позволяет задать общую логику (стратегию), а отдельные разрезы/показатели окрасить вручную в нужные цвета.
- Удаление цвета из ячейки на вкладке **«Данные»** *не отключает* локальную логику цвета.
Чтобы локальный цвет действительно снять:

- Откройте всплывающее окно настроек конкретного разреза или показателя.

# Круговая диаграмма | Документация Fastboard

Source: https://help.fastboard.online/user/biblioteka-widgetov/vse-diagr/krugovaia-diagramma/

**Круговая диаграмма** представляет собой визуализацию данных в форме круга, который делится на сектора. Площадь каждого сектора соответствует величине соответствующей категории.

**Рекомендуется использовать от 5 до 7 категорий**, не более 10. Если количество категорий превышает этот предел, стоит объединить менее значимые категории в общий сектор «Прочее».

Круговые диаграммы применяются для наглядного отображения соотношения частей к целому. Например, с их помощью можно: • показать **процентное распределение** различных категорий; • сравнить **относительные доли** нескольких категорий; • выделить **ключевые сегменты** данных.

### **Модель данных**[​](#модель-данных)

Позволяет выбрать одну из моделей данных, ранее созданных в конструкторе моделей данных. Данные из этой модели будут использоваться для данного визуального компонента. Все визуальные компоненты использующие одну модель будут связаны через нее, то есть будут фильтровать эту модель и реагировать на ее фильтрацию. Такой подход будет полезен, если требуется отделить или изолировать какие-то данные используя общее хранилище.

### **SQL (язык структурированных запросов)**[​](#sql-язык-структурированных-запросов)

Редактор SQL позволяет вручную редактировать запрос данных. Скрипт редактора кода связан с выбором данных в интерфейсе. Когда вы выбираете поле для разреза и показателя в панели настроек, система генерирует SQL-запрос (запросы на структурированном языке). И этот запрос затем можно изменить в редакторе. Например, прописать другое поле для разреза и при сохранении изменений это поле изменится в интерфейсе. Кроме простого выбора поля в редакторе можно писать сложные выражения.

**Интерфейс редактора** состоит из полей:

- **Разрезы**
- **Показатели**
- **Группировки и фильтры**

- Цвет текста;

Поля настройки:

- **Инициировать фильтрацию.** Включает фильтрацию при нажатии на разрез визуального компонента.

- **Реагировать на собственные фильтры.** Включает будет ли применен собственный фильтр к визуальному компоненту.
- **Реагировать на drilldown в других визуальных компонентах.** Включает реагирования визуального компонента при переходе на другие разрезы в других визуальных компонентах.

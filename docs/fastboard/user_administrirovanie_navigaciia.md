# Навигация в панели администрирования | Документация Fastboard

Source: https://help.fastboard.online/user/administrirovanie/navigaciia/

Эта инструкция показывает, как ориентироваться в панели администрирования Fastboard и где находятся ключевые разделы для управления системой.

Предусловие: вы вошли под пользователем с доступом к панели администратора.

Зайти в панель администратора можно с главной страницы приложения в Менеджер проектов.

![Frame 60.png](https://book.winsolutions.ru/uploads/images/gallery/2026-03/scaled-1680-/frame-60.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2026-03/scaled-1680-/frame-60.png)):
> 1) Тема интерфейса  
> Панель администратора  
> Помощь  
> Выход  
> 2) Скриншот показывает выпадающее меню с пунктами настроек и выхода в BI-платформе Fastboard.


Навигация по интерфейсу:

(1) Выход из панели администратора - «стрелка назад». (2) Большая часть разделов панели администратора собрана типовым шаблоном, где слева изображен список сущностей выбранного раздела. (3) Навигация по всем разделам. (4) А при выделении одного сущности выбранного раздела, в центральной части (4) отображаются параметры, соответствующие текущей вкладке этого раздела.

> 2) Скриншот показывает интерфейс управления тенантом «ООО Компания» в BI-платформе Fastboard, включая навигацию по организациям слева и вкладки для управления пользователями, группами, потоками, подключениями, активными директориями, лицензиями и разрешениями.



## Ожидаемый результат[​](#ожидаемый-результат)

Вы уверенно переходите между разделами администрирования, понимаете назначение центральной рабочей области и быстро находите нужные настройки.

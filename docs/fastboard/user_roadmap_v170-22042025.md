## **Стилизация кнопочного фильтра**[​](#стилизация-кнопочного-фильтра)

Все это для трех состояний кнопки: Свободное, Активное, Заблокированное.

### **Программируемое управление видимостью визуальных компонентов**[​](#программируемое-управление-видимостью-визуальных-компонентов)

Функционал, который дает возможность скрывать и показывать визуализации по клику на кнопку, созданную с помощью медиаблока. Обеспечивается это тремя новыми секциями:

- В настройках страницы появилась **секция «Триггеры»**. Триггер это булевая переменная, которая возвращает только два значения true, либо false. Триггер действует только в рамках своей страницы. В настройках триггера можно изменить текущее значение. По умолчанию установленно в true
- В событиях визуальных компонентов появилась **секция «Управление видимостью»**. Активация данной секции переключает управление видимостью визуального компонента с ручного (клик на «глазик» в диспечере объектов) на программное — через триггер. В этой секции необходимо выбрать тот самый триггер созданный на вкладке страницы. Когда значение триггера равно true визуальный компонент видим на странице. Если переключить значение триггера в false визуальный компонент станет невидимым
- Также в событиях медиаблока (только его) появилась **секция «Управление триггерами»**. Активация этой секции позволяет кликом на медиаблок присвоить следующие значения триггерам: true, false, invert. Последнее меняет значение на противоположное
Чтобы реализовать связку:

- Создаем триггер на вкладке страницы
- Переходим в события визуального компонента который хотим скрывать. На вкладке «События» в активируем секцию «Управление видимостью». В выпадающем списке выбираем созданный триггер ![image.png](https://book.winsolutions.ru/uploads/images/gallery/2025-03/scaled-1680-/HAfimage.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2025-03/scaled-1680-/HAfimage.png)):
> Управление видимостью  
> Триггер 0  
> Триггер 0  
> Триггер 1  
> Переход по гиперссылке  
> Скриншот показывает интерфейс управления видимостью элементов в BI-платформе Fastboard с раскрывшимся списком триггеров и курсором, указывающим на один из пунктов.

- Создаем кнопку с помощью визуального компонента медиаблок. На вкладке «События» переходим в секцию «Управление триггерами». Добавляем триггер. В дополниетельном селекте триггера выбираем значение которое хотип присвоить при к лике на кнопку. ![image.png](https://book.winsolutions.ru/uploads/images/gallery/2025-03/scaled-1680-/xYhimage.png)

### **Экспорт страницы дашборда в JPG**[​](#экспорт-страницы-дашборда-в-jpg)

Теперь страницу дашборда можно экспортировать не только в JSON (расширение файла) но и в JPG. При экспортировании страниц система уточнит формат. Если будет выбран JPG, то откроется диалоговое окно с выбором папки для сохранения изображение.

*Обращаем внимание.* В JPG сохранится именно активная страница.

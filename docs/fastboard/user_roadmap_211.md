## Доработки[​](#доработки)

**Опциональность S3** S3 больше не обязателен для работы хранилища: инсталляцию можно поднять на файловом хранилище без S3.

**Права в списке источников** В ответ на запрос списка источников данных добавлены права текущего пользователя — корректнее отображаются доступные действия по подключениям.


## Багфикс[​](#багфикс)


### Хранилище, лицензии и роли[​](#хранилище-лицензии-и-роли)

- Админ системы может выдать лицензию организации, даже если не состоит в ней участником.
- Исправлена ошибка смены роли у участников тенанта с активной лицензией («Ошибка изменения роли» / «Пользователя не существует в вашей лицензии»).
- В модальном окне выдачи доступа к хранилищу организации больше не показываются пользователи всех организаций — только релевантный список.
- У админа системы / админа тенанта без доступа к лицензиям закрыт лишний функционал лицензий в других разделах админ-панели.
- В разделе лицензий корректно подтягиваются данные выбранной организации (исправлен неверный запрос).

### Подключения и файловые источники[​](#подключения-и-файловые-источники)

- Исправлена ошибка при создании коннектора с источником CSV.
- При создании подключения с файловым источником снова уходит запрос `/api/v2/source/id/tables` с данными источника.
- В модальном окне редактирования подключения снова отображается файловый источник.
- При обновлении предпросмотра CSV в запрос `file-preview` корректно передаётся параметр `file`.
- Для разделителя «Авто» в форме редактирования CSV больше не подставляется значение «А».
- В выпадающем списке разделителя значение «Авто» отображается на русском, а не как `Auto`.
- Исправлена логика приписки к имени файла при повторных загрузках одного и того же файла.

### Проекты и навигация[​](#проекты-и-навигация)

- При копировании проекта из черновика в поток проект снова отображается в потоке.
- Исправлено перемещение страниц в навигационном меню проекта.
- При переупорядочивании страниц скрытые страницы больше не учитываются как видимые позиции.
- Исправлено смещение проектов с сокращённым названием в режиме списка.
- Исправлено расположение меню навигации страниц в хедере.

### Таблицы, дашборды и конструктор[​](#таблицы-дашборды-и-конструктор)

- При сортировке по колонкам таблицы с раскрытой детализацией уровень детализации больше не сбрасывается.
- Фильтрация по колонке «Изменена» больше не очищает данные на всём дашборде.
- Устранён спам запросов `get_data` с ответом 403 из-за таблиц в проекте.
- Исправлена ошибка выполнения запроса виджета (регресс: некорректная генерация SQL со строковыми литералами в условиях).
- Исправлено отображение тултипов в интерфейсе.
- Исправлена видимость кнопок листания страниц в навигации хедера.
- В редакторе кода исправлено поведение `Shift+Enter` при открытом списке подсказок автодополнения.
- У зрителя при входе в проект доступного потока больше не уходит лишний запрос `/api/v1/models/get_fields` с ошибкой 409.

### Отчёт об ошибках[​](#отчёт-об-ошибках)

- Исправлены ошибки и несоответствия при записи отчёта об ошибках.
- Контекстные меню хедера больше не перекрываются модальным окном «Подготовка отчёта об ошибке».

### Прочее[​](#прочее)

- Исправлена грамматическая ошибка в уведомлении при смене пользователя.

# Откатить проект | Документация Fastboard

Source: https://help.fastboard.online/user/rabota-s-proektami/sozdanie-i-upravlenie-proektami/otkatit-proekt/

В этой инструкции рассмотрим как откатить проект до предыдущей версии, учитывая все сохранения и изменения, произведенные в процессе работы и как управлять стратегией хранения версий.

Во время работы с проектом при каждом нажатии на кнопку «Сохранить» в истории проекта **создается новая точка восстановления.** Таким образом в проекте **хранится история его изменений**. В информации о событии сохранения содержится время сохранения и логин пользователя который произвел это сохранение. При необходимости можно восстановить какое-либо из сохраненных состояний, то есть **откатить, к нужной версии**.


## **Откатить к предыдущей версии**[​](#откатить-к-предыдущей-версии)

Откатить к предыдущей версии можно двумя путями.

- В правом нижнем углу каждого проекта есть **кнопка "инфо"** ![Frame 38 (3).png](https://book.winsolutions.ru/uploads/images/gallery/2025-12/scaled-1680-/frame-38-3.png), которая открывает боковую панель. Там, перейдите во вкладку **"Версии"** и выберите нужную из списка.

### **Создать копию версии**[​](#создать-копию-версии)

Если вы не хотите терять текущую версию проекта, вы можете сделать копию сохраненной ранее версии. Из выбранной версии будет создана **независимая копия**. Для нее на следующем шаге нужно будет повторить действия как при копировании: выбрать поток, ввести название, отметить переключатели (заменить существующий проект и запустить импорт данных) и подтвердить нажатием на кнопку "Копировать".

### **Стратегия хранения версий**[​](#стратегия-хранения-версий)

Изменять стратегию хранения версий проектов может только пользователь с ролью "Администратор". Если вы таковым являетесь, перейдите в панель администратора раздел **"Настройки"**. В этом разделе настраивается стратегия хранения версий проектов, предлагая две стратегии: **"Количество" и "Возраст"**

Подробнее о стратегиях хранения версий [тут.](https://users-docs-dev.fb-dev.winsolutions.ru/administrirovanie/razdel-nastroiki/vkladka-sistema/)

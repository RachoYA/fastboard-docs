# Комбинированная диаграмма | Документация Fastboard

Source: https://help.fastboard.online/user/biblioteka-widgetov/vse-diagr/kombinirovannaya/

**Комбинированная диаграмма** сочетает в себе два или более типов графиков на одном холсте. Этот метод позволяет наглядно демонстрировать связи между различными наборами данных, особенно когда они отличаются по масштабам или единицам измерения.

Комбинированная диаграмма служит эффективным инструментом для **визуализации взаимосвязей** между различными показателями. К примеру, можно заметить, что увеличения объема продаж часто совпадают с ростом дохода, или же, наоборот, что периоды наивысшей маржи могут совпадать с уменьшением объемов продаж.

### **Модель данных**[​](#модель-данных)

Позволяет выбрать одну из моделей данных, ранее созданных в конструкторе моделей данных. Данные из этой модели будут использоваться для данного визуального компонента. Все визуальные компоненты использующие одну модель будут связаны через нее, то есть будут фильтровать эту модель и реагировать на ее фильтрацию. Такой подход будет полезен, если требуется отделить или изолировать какие-то данные используя общее хранилище.

Ниже пример визуализации с несколькими разрезами.

**В режиме реальных данных м**ожно добавлять любое количество разрезов. Принципиально важен их порядок – значения из последующего разреза будут восприниматься системой как цели для потоков из текущего разреза.

Также, о разрезах можно почитать 👉 [тут](https://help.fastboard.online/konstruktor-dasbordov/parametry-vidzeta/#%D1%80%D0%B0%D0%B7%D1%80%D0%B5%D0%B7%D1%8B)

### **Работать как фильтр**[​](#работать-как-фильтр)

Позволяет визуальному компоненту выступать в роли фильтра.

![Снимок экрана 2026-01-22 в 02.22.48 1.png](https://book.winsolutions.ru/uploads/images/gallery/2026-01/scaled-1680-/snimok-ekrana-2026-01-22-v-02-22-48-1.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2026-01/scaled-1680-/snimok-ekrana-2026-01-22-v-02-22-48-1.png)):
> 1)  
> Работать как фильтр  
> Иницировать фильтрацию  
> Применить ко всем листам  
> Добавлять несколько фильтров  
> Реагировать на собственные фильтры  
> Реагировать на drilldown в других виджетах  
> Влияние на виджеты  
> Настроить  
> Применить ко всем  
> 2) Скриншот показывает панель настроек фильтрации виджета в BI-платформе Fastboard с переключателями и кнопками управления поведением фильтра.


Поля настройки:

- **Инициировать фильтрацию.** Включает фильтрацию при нажатии на разрез визуального компонента.
- **Применить ко всем листам.** Включает применение фильтра на все листы или только на текущий.
- **Добавлять несколько фильтров.** Включает многократное добавление фильтра при нажатии на разрез или добавляет один фильтр с заменой при последующих нажатиях.
- **Реагировать на собственные фильтры.** Включает будет ли применен собственный фильтр к визуальному компоненту.
- **Реагировать на drilldown в других визуальных компонентах.** Включает реагирования визуального компонента при переходе на другие разрезы в других визуальных компонентах.

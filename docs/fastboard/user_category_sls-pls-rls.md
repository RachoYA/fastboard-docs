# SLS, PLS и RLS | Документация Fastboard

Source: https://help.fastboard.online/user/category/sls-pls-rls


## 📄️ SLS

Как работает Stream Level Security в Fastboard: разграничение доступа к потокам, назначение пользователей и групп, а также выдача разных прав на уровне потока.


## 📄️ PLS

Описание Pages Level Security в Fastboard: ограничение доступа к отдельным страницам проекта, исключение пользователей и поведение прямых ссылок для недоступных разделов.


## 📄️ RLS

Принципы Row Level Security в Fastboard: настройка правил на уровне строк, привязка переменных к пользователям и примеры фильтрации данных по учетной записи.

**Режим просмотра**

Активирует режим имитирующий работу в режиме просмотра, при котором выделение визуальных компонентов, их перемещение по странице и изменение размеров заблокировано.

**Модель данных по умолчанию**

Устанавливает модель данных, которая будет выбрана при создании новых визуальных компонентов.

**Реальные данные**

Переключатель управляет тем будут ли отображены реальные данные (если они загружены) в визуализациях проекта. Режим "Принудительно" позволяет обойти локальные настройки визуальных компонентов, влияя на весь проект целиком.

- **Показать данные, вкл:** Если были загружены данные из источников, создана модель и в визуализациях выбраны соответствующие поля показателей и разрезов, пользователь увидит на графиках реальные цифры полученные из базы данных
- **Показать данные, выкл:** Во всех визуализациях будут показаны автоматически сгенерированные [виртуальные данные.](https://help.fastboard.online/konstruktor-dasbordov/virtualnye-dannye/)
**Локальный шрифт**

Позволяет выбрать и изменить шрифт на всей странице.

**Шаг сетки**

Количество пикселей, служащее единицей измерения экранного пространства при перемещении и изменении визуализаций.

**Масштабирование страницы**

Задает конкретную ширину страницы вне зависимости от ширины устройства.

**Предпросмотр RLS (механизм безопасности на уровне строк)**

Механизм разграничения доступа к данным. Позволяет скрывать определённые строки в таблицах, документах или справочниках для конкретных пользователей

# Руководство Гос. организаций | Документация Fastboard

Source: https://help.fastboard.online/gostech/

Приветствуем Вас в базе знаний Fastboard для контура Государственных организаций. Здесь Вы узнаете, как устроена наша BI-система, познакомитесь с ее возможностями и узнаете, как наиболее эффективно их использовать.

Программа Fastboard предназначена для комплексного формирования аналитической отчетности, извлечения данных из источников, их обработки и визуализации для последующего анализа с целью принятия стратегических и управленческих решений.

Результатом работы ПО являются аналитические порталы, Интерактивные отчёты и интерактивные аналитические отчёты по ключевым направлениям, включающие рабочие группы отчётности с различным уровнем доступа либо отдельные Интерактивные отчёты — в зависимости от задач компании и/или менеджмента.

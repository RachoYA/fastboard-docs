5 элементов


## 📄️ Выбор данных для загрузки

Инструкция по выбору таблиц и полей источника в Fastboard: запуск импорта через скрипт загрузки, переименование сущностей и назначение типов данных столбцов.


## 📄️ Редактор скрипта загрузки

Описание ручного редактирования скрипта загрузки в Fastboard: добавление источников и таблиц, создание вычисляемых полей, календаря и учет особенностей MS SQL.


## 📄️ Обновление по расписанию

Как настроить расписание обновления данных в проекте Fastboard: выбор периодичности или CRON, активация задачи и контроль всех запусков через раздел «Задания».


## 📄️ Инкрементное обновление

Как перевести скрипт Fastboard с полной перезаписи на инкрементную загрузку: изменение порядка секций, замена DROP на ALTER и обновление только последних данных.


## 📄️ Раздельное обновление источников

Сценарий раздельного обновления источников в Fastboard: вынос тяжелой загрузки в отдельный проект, правка скрипта и ссылка на таблицу через идентификатор проекта.

# Быстрое сшивание дашбордов через импорт/экспорт | Документация Fastboard

Source: https://help.fastboard.online/user/konstruktor-dasbordov/bystroe-ssivanie/

**Сшивание** — это перенос одной или нескольких страниц из одного проекта в другой с сохранением их структуры, настроек и визуального оформления. Используется для:

- Повторного использования страниц,
- Ускорения разработки,
- Модульной сборки проектов.

## **Экспорт страницы**[​](#экспорт-страницы)

- Откройте проект, содержащий нужную страницу.
- В левом боковом меню откройте раздел «Страницы».
- Выделите необходимую страницу.
- Выберите опцию **«Экспортировать»**.
- Скачанный файл будет содержать все элементы страницы (без данных).

### **Импорт страницы в другой проект**[​](#импорт-страницы-в-другой-проект)

- Откройте проект, в который нужно добавить страницу.
- В панели управления страницами нажмите **«Импортировать»**.
- Выберите ранее экспортированный файл страницы.
- При необходимости настройте параметры импорта или оставьте значения по умолчанию.
- После завершения процесса страница появится в списке доступных страниц проекта.

При импорте страницы **данные не переносятся автоматически**. Источники данных нужно подключить отдельно в новом проекте.


### **Альтернативный способ — копирование проекта**[​](#альтернативный-способ--копирование-проекта)

В случае, если необходимо перенести **весь дашборд (отчёт)**, а не отдельную страницу:

- Можно использовать функцию **дублирования проекта**.
- Подходит для шаблонных решений или создания новой версии на основе текущей.

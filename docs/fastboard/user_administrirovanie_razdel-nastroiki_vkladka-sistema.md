# Настройки: вкладка «Система» | Документация Fastboard

Source: https://help.fastboard.online/user/administrirovanie/razdel-nastroiki/vkladka-sistema/

В данном разделе вы можете настроить стратегию хранения версий проектов. Существует **две стратегии**.


## **Стратегия "Количество"**[​](#стратегия-количество)

Вы можете установить максимальное количество последних версий, которые будет хранить система. Значение по умолчанию составляет 100 версий. При каждом последующем сохранении, самая старшая версия будет удаляться автоматически.


### **Стратегия "Возраст"**[​](#стратегия-возраст)

Это альтернатива “Количеству”, вы можете выбрать срок хранения проектов. Если проект не будет подвергаться изменениям в течение указанного количества дней, он будет автоматически удалён.

> Скриншот показывает настройки стратегии хранения версий проектов в BI-платформе Fastboard, включая выбор между ограничением по количеству или возрасту версий и кнопку применения настроек.


После нажатия "Применить стратегию" выбранная вами стратегия будет сохранена. Обратите внимание, что в соответствии с новой стратегией из истории проектов будут **удалены** версии, не соответствующие установленным условиям.

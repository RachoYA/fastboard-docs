# Обновление по расписанию | Документация Fastboard

Source: https://help.fastboard.online/user/dispetcer-dannyx/obnovlenie-po-raspisaniiu/

Эта инструкция описывает процесс настройки обновления данных в проекте, как выбрать периодичность обновления, и управлять расписанием задач через панель администратора.


## **Настройка расписания обновлений**[​](#настройка-расписания-обновлений)

Откройте список проектов и выберите любой проект, который вас интересует. Перейдите в раздел Диспетчер данных. ![Снимок экрана 2025-12-10 в 00.56.25 2 (2).png](https://book.winsolutions.ru/uploads/images/gallery/2026-02/scaled-1680-/snimok-ekrana-2025-12-10-v-00-56-25-2-2.png)

В каждой вкладке есть кнопка **«Обновление данных»**. Нажмите на нее.

После нажатия на кнопку «Обновление данных» откроется окно выбора графика. Выберите периодичность обновления данных:

- Ежечасно
- Ежедневно
- Еженедельно
- Ежемесячно
- CRON

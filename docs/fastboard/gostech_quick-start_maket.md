### **Вставка визуального компонента на страницу**[​](#вставка-визуального-компонента-на-страницу)


#### Существует два способа добавления визуального компонента:[​](#существует-два-способа-добавления-визуального-компонента)

**Способ 1:** Выберите нужную визуализацию, кликнув по ней левой кнопкой мыши, затем нажмите в любом месте рабочей области, чтобы вставить её. Размеры визуального компонента будут установлены автоматически.

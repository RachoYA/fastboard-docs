# SLS | Документация Fastboard

Source: https://help.fastboard.online/user/sls-ols-pls/sls/

**SLS (Stream Level Security)** позволяет ограничивать доступ к потокам.

Политика настройки доступа: разрешающая. Доступ к потоку разрешается только перечисленным пользователям или группам пользователей (далее – ГП).

*Например,* есть два потока: Финансы и Логистика. Как правило сотрудники одного департамента не должны видеть Содержимое других подразделений.

У каждого потока есть вкладка Доступ, на которой вы можете управлять пользователями или ГП, у которых будет доступ к этому потоку.

Например, для отчётов по финансам это группы пользователей Финансисты и Бухгалтеры.

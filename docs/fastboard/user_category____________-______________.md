# Технические характеристики Fastboard | Документация Fastboard

Source: https://help.fastboard.online/user/category/технические-характеристики


## 📄️ Архитектура системы

Состав и взаимодействие компонентов Fastboard: API и Golang-модули, хранилища ClickHouse/PostgreSQL/Redis, сервисные процессы и обмен задачами через RabbitMQ.


## 📄️ Технические требования к железу

Минимальные и рекомендуемые технические требования для Fastboard: поддерживаемые ОС, ресурсы CPU/RAM/SSD, версии Docker и состав используемых баз данных.


## 📄️ Типы лицензий

Сравнение ролей и лицензий Fastboard: права администратора, разработчика, аналитика и зрителя, а также ограничения для организационных и тенантных администраторов.


## 📄️ Установка системы с SSL

Инструкция по установке Fastboard с SSL: настройка Traefik, DNS и сертификатов, запуск сервисов в Docker и активация первого ключа после успешного развертывания.


## 📄️ Установка системы без SSL

Пошаговое развертывание Fastboard без SSL: подготовка контейнеров PostgreSQL, ClickHouse, Redis и RabbitMQ, запуск backend/frontend и первичная активация лицензии.

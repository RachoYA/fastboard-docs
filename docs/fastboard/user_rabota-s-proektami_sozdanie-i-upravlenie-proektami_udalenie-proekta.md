# Удаление проекта | Документация Fastboard

Source: https://help.fastboard.online/user/rabota-s-proektami/sozdanie-i-upravlenie-proektami/udalenie-proekta/

Удаление проекта — это окончательное действие, которое приводит к полному удалению всех данных, связанных с проектом.

Удаление это необратимое действие, его нельзя отменить.

Выберите проект, который вы хотите удалить. Вызовите меню на правую кнопку мыши и нажмите на действие «Удалить».

Появится окно с запросом на подтверждение удаления. Если вы уверены в своем решении, подтвердите удаление, нажав на кнопку «Удалить».

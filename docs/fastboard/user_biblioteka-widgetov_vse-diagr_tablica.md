## **Вкладка «Данные»**[​](#вкладка-данные)

Для построения необходимы **разрезы** (измерения) и/или **показатели** (меры) (неограниченно), и те, и другие являются столбцами таблицы

Можно изменять порядок показателей, порядок разрезов, переместить показатель в разрез и наоборот. Однако **на первом месте всегда располагается разрез**

**[Дополнительно к стандартным](https://help.fastboard.online/konstruktor-dasbordov/parametry-vidzeta/)** основным секциям в этом визуальном компоненте добавится:

### **Параметры разрезов**[​](#параметры-разрезов)

Помимо [**стандартных**](https://help.fastboard.online/konstruktor-dasbordov/parametry-vidzeta/)секций для простой таблицы предусмотрены следующие:


#### **Задать ширину столбца**[​](#задать-ширину-столбца)

При активной настройке ширина столбца задается вручную в пикселях


#### **Группировать**[​](#группировать)

Сгруппирует (свернет под «плюсик») все разрезы которые идут после этого. То есть в каждом значении верхнеуровнего разреза при раскрытии будут все значения вложенного. И так по цепочке до самого последнего. Активация будет доступна только если этот разрез первый в списке, либо в предыдущем разрезе эта настройка уже активирована.

### **Строка итогов**[​](#строка-итогов)

При активной настройке в таблице будет показана строка с итогами для показателей, в которых была включена настройка «[Рассчитать итог](https://users-docs-dev.fb-dev.winsolutions.ru/biblioteka-widgetov/vse-diagr/tablica/)».

**Расположение** строки итогов может быть сверху таблицы, так и снизу


### **Шапка**[​](#шапка)

При активации соответствующих переключателей строка заголовков («шапка») таблицы будет показана либо скрыта. Настройки содержат стандартные параметры работы с цветом и текстом.


### **Тело таблицы**[​](#тело-таблицы)

- **Отбивка столбца разрезов**
*При активации соответствующих переключателей набор столбцов с разрезами таблицы будет отделен от столбцов с показателями фоном, жирной линией либо и тем, и другим.*

- **Отбивка шапки**
*При активации соответствующих переключателей строка заголовков («шапка») таблицы будет выделена фоном, жирной линией либо и тем, и другим.*

- **Отбивка строки итогов**
*При активации соответствующих переключателей строка итогов таблицы (если она включена) будет выделена фоном, жирной линией либо и тем, и другим.*

- **Отбивка строк**
*При активной настройке строки заливаются цветом через одну.*

- **Внутренний отступ в ячейках**
*Для данного визуального компонента предусмотрено управление внутренними расстояниями по вертикали и горизонтали.*

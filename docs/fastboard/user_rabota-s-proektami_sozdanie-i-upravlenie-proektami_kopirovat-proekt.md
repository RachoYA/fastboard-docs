## **Копировать проект**[​](#копировать-проект)

Копирование проекта в системе позволяет создавать новые версии существующих проектов, которые могут быть использованы для различных целей, таких как работа с черновиками или обновление содержимого.


### **Выбор источника копирования**[​](#выбор-источника-копирования)

Проект можно копировать из следующих источников:

- **Потока**: выберите проект из активного потока.
- **Черновиков**: выберите проект из списка черновиков.
- **Административной панели**: выберите проект из панели администратора, если у вас есть соответствующие права доступа.

Предусмотрено два вида копирования, то есть **два сценария**. Простое и копирование с заменой. Ниже рассмотрим оба сценария подробнее.


### **Сценарий 1.** Простое копирование[​](#сценарий-1-простое-копирование)

Кликните на выбранный проект левой кнопкой мыши и выберите пункт "Копировать"

Во всплывающем окне выбрать **поток,** в который требуется скопировать проект.

Изменить **название,** если требуется создать независимую копию.

Подтвердить нажатием на кнопку «**Копировать**».

Будет создана новая копия проекта.

### **Сценарий 2.** Копирование с заменой[​](#сценарий-2-копирование-с-заменой)

- Кликните на выбранный проект левой кнопкой мыши и выберите пункт "Копировать"
- Во всплывающем окне выбрать **поток,** в который требуется скопировать проект.
- Поставить переключатель «**Заменить существующий проект**».
- **Выбрать проект,** который необходимо заменить.
- Подтвердить нажатием на кнопку «**Заменить**».
- Содержимое проекта будет заменено скопированным. Ссылка на проект останется неизменной. Технически произойдет обновление версии проекта.

### **Семантическая модель (смысловые связи между объектами и их атрибутами)**[​](#семантическая-модель-смысловые-связи-между-объектами-и-их-атрибутами)

При копировании создается независимая копия семантической модели проекта. Копия и оригинал **не взаимосвязаны**, что позволяет вносить изменения в одну модель без влияния на другую.

При копировании проекта автоматически создается задача на обновление семантической модели. Выполнение этой задачи может занять некоторое время. **Важно, дождаться завершения процесса копирования,** чтобы избежать ошибок.


### **Получение новой ссылки**[​](#получение-новой-ссылки)

После завершения процесса копирования у нового проекта будет создана уникальная ссылка. Сохраните эту ссылку для дальнейшего доступа к скопированному проекту.

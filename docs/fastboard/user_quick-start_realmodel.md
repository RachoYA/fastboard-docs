# Подключение визуала к данным из реальной модели | Документация Fastboard

Source: https://help.fastboard.online/user/quick-start/realmodel/

В этой инструкции рассматривается пошаговое подключение визуала к данным из реальной модели, подготовке и загрузке данных, охватывая процесс подключения источников, выбор необходимых таблиц, сохранение и запуск скриптов, а также создание связей между таблицами и настройку визуализаций.


## **Шаг 1: Доступ к диспетчеру данных**[​](#шаг-1-доступ-к-диспетчеру-данных)

Для подготовки реальных данных для Вашей визуализации перейдите на экран диспетчера данных, нажав кнопку в правом верхнем углу страницы. Данная функция **доступна только пользователям с правами разработчика и администратора**.

#### **Шаг 6: Добавление таблицы на лист**[​](#шаг-6-добавление-таблицы-на-лист)

Нажмите на название таблицы, чтобы добавить ее на лист. Обратите внимание, что таблицы при добавлении на лист наслаиваются друг на друга. Их можно перемещать, выделив верхнюю таблицу и перетаскивая в нужное место.

Если в модели данных только одна таблица, добавьте ее на лист, нажмите "Сохранить" и переходите к **Шагу 9**.

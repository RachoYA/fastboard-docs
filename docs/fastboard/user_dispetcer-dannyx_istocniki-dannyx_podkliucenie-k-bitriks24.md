# Создание подключения «Битрикс24» | Документация Fastboard

Source: https://help.fastboard.online/user/dispetcer-dannyx/istocniki-dannyx/podkliucenie-k-bitriks24/

Для подключения к **API Битрикс24** нужно получить API‑key в админском аккаунте и сформировать URL вебхука. При работе важно учитывать лимиты: не более 2 запросов одновременно для базовых тарифов (5- для «Энтерпрайз») и ограничение в 480 секунд на выполнение запросов за 10 минут. Подключитесь, протестируйте соединение кнопкой «Тестовое подключение», проверьте выборку данных через «Предпросмотр» и сохраните настройки кнопкой «Создать».

## Подготовка данных для подключения[​](#подготовка-данных-для-подключения)

Получите API‑key в админском аккаунте Битрикс24 (в настройках).

Сформируйте URL вебхука на основе данных вашего аккаунта (адрес для взаимодействия с API, формируется на основе данных вашего аккаунта Битрикс24)


### Основные ограничения API[​](#основные-ограничения-api)

При работе с API важно учитывать лимиты:

Лимит интенсивности запросов:

- Для тарифов кроме «Энтерпрайз»: не более 2 одновременных запросов, счётчик уменьшается на 50 раз в секунду.
- Для тарифа «Энтерпрайз»: не более 5 одновременных запросов.
- При превышении — ошибка 503 (Query_limit_exceeded).
**Лимит ресурсоёмкости:** если суммарное время выполнения запросов превышает 480 секунд за 10 минут, метод блокируется.

**Пагинация:** данные возвращаются порциями по 50 записей (параметр start задаёт смещение).

**Batch‑запросы:** до 50 подзапросов в одном запросе, максимум 2500 строк (50×50) за раз.


### Поддерживаемые данные[​](#поддерживаемые-данные)

Через API доступны:

- Все GET‑методы из CRM: сделки, лиды, контакты, компании, коммерческие предложения.
- Один GET‑метод из БП и роботов: «Получить список бизнес‑процессов».
- Три GET‑метода из Задач: поля задачи, список задач, история задачи.

### Проверка вебхука (взаимодействия между веб-сервисами)[​](#проверка-вебхука-взаимодействия-между-веб-сервисами)

- Выполняется GET‑запрос к URL с тестовым запросом (например, получение одной записи).
- Если ответ:
- HTTP 200 и валидный JSON — подключение успешно, открывается окно выбора сущности.
- Ошибка (например, 403, 404 или невалидный формат) — отображается сообщение: «Не удалось установить подключение. Получена ошибка:» + текст ошибки.

> Скриншот показывает интерфейс создания подключения к источнику данных (CRM → Сделки) с возможностью настройки фильтрации по полю DATE_CREATE и управления поведением при ошибках.


- Раскрывающийся список **«Источник»** — варианты: «CRM», «Задачи», «Бизнес‑процессы», «Copilot» (по умолчанию — «CRM»).
- Дополнительный раскрывающийся список (появляется при выборе «CRM») — варианты: «Сделки», «Лиды», «Компании», «Коммерческие предложения», «Смарт‑процессы» (по умолчанию — «Сделки»).
Чекбокс **«Прерывать последовательность запросов в случае ошибки»** — по умолчанию активен (передаёт параметр `halt=1`, иначе `halt=0`)

Строка фильтрации (в одну строку):

- Поле ввода **«Поле»** — по умолчанию `DATE_CREATE`.
- Раскрывающийся список операндов: `=`, `!=` (`!`), `>=`, `>`, `<=`, `<`, `LIKE` (`%`).
- Поле ввода **«Значение»**.
- Кнопка **«Добавить»** (`+`) — создаёт новую строку фильтрации (по умолчанию `DATE_CREATE`, `=`, пустое значение).
- Кнопка **«Удалить»** — появляется при наведении, удаляет строку без подтверждения.
- Кнопка **«Тестовое подключение»** — отправляет пустой POST‑запрос, проверяет подключение.
- Кнопка **«Создать»** — формирует подключение к Битрикс (новый источник).
- Кнопка **«Назад»** — возвращает во внутреннее окно источника.

### **Особенности фильтрации**[​](#особенности-фильтрации)

Поле нечувствительно к регистру, условие — чувствительно.

При добавлении строк:

- До 4 строк — элементы сдвигаются вниз.
- От 4 строк и более — добавляется прокрутка, элементы не сдвигаются.

#### **Важно**[​](#важно)

- Для базовых тарифов — не более **2 одновременных запросов**, для «Энтерпрайз» — не более **5**.
- Суммарное время выполнения запросов не должно превышать **480 секунд за 10 минут**.
- Добавляйте **задержки между запросами**, чтобы не превысить лимиты.

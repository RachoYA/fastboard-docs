## **Доработки**[​](#доработки)


### **Улучшена обработка SVG-изображений**[​](#улучшена-обработка-svg-изображений)

Исправлена корректная отрисовка SVG-файлов, структура которых предполагает дополнительную обёртку содержимого в корневой групповой элемент. Ранее такие файлы могли отображаться некорректно — иконки или графика не появлялись либо рендерились неправильно. Теперь парсер учитывает подобную структуру, и SVG-ресурсы отображаются корректно вне зависимости от того, обёрнуто ли содержимое файла в или нет.

### **Багфикс**[​](#багфикс)


#### **Пользователи, организации и авторизация**[​](#пользователи-организации-и-авторизация)

- Исправлен некорректный выход из системы при добавлении лицензии на публикации без действующей базовой лицензии.
- Снято ограничение на уникальность логина в рамках всей системы — теперь можно создавать пользователей с одинаковым логином в разных организациях.
- Исправлена деавторизация существующего аккаунта при создании пользователя с дублирующимся логином в другом тенанте.
- Исправлено множественное выделение пользователей с одинаковым именем из разных организаций при клике на одного из них.
- В запрос `api/v2/source/check-source-name` теперь корректно передаётся параметр `tenant_id` при создании подключения с одинаковым названием в разных тенантах.
- Исправлено автозаполнение полей «Логин» и «Пароль» данными учётной записи пользователя в модальном окне создания подключения «База данных».
- При клике на подключение из списка теперь корректно отправляется запрос `/api/v2/source/id/tables`.
- Исправлено отображение доступных потоков.
- Поля типа `date` в MySQL больше не конвертируются в `datetime`.
- Исправлено падение фильтра «Календарь» с ошибкой при активации реальных данных.
- Устранена ошибка при добавлении условия в фильтр.
- Исправлено дублирование элементов в выборке при работе с фильтрами в проекте.
- Исправлена обработка чисел с плавающей точкой в условиях маркера.
- Исправлено отображение названия оси показателей.
- Добавлена настройка отступов для значений на узлах.
- Исправлены названия отступов при вертикальной ориентации значений.
- Исправлены перепутанные иконки в секциях пропорций изображений.
- Исправлены перепутанные иконки и тултипы.
- Запрещено сохранение модели данных с пустым именем.

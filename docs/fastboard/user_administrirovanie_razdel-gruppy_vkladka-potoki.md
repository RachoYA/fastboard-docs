# Группа: вкладка «Потоки» | Документация Fastboard

Source: https://help.fastboard.online/user/administrirovanie/razdel-gruppy/vkladka-potoki/

Вкладка "Потоки" предназначена для управления доступом к потокам для выбранного тенанта.

Все потоки, к которым предоставлен доступ, будут отображаться в списке менеджера проектов для участников этого тенанта.

На текущей странице можно выделить тенант (1) и к выделенной группе (2) добавить доступ к потокам (3). Пользователи тенанта увидят все эти потоки в своем списке в менеджере проектов.

**Добавление потока в тенант**

- Нажмите кнопку «Добавить», чтобы открыть модальное окно выбора потока
- Выберите поток с помощью поисковой строки
- Отметьте набор прав доступа для тенанта

**Редактирование или удаление потока**

Наведите курсор на нужный поток:

- Для редактирования прав доступа нажмите на иконку «Карандаш».
- Для удаления нажмите на иконку «Корзинка» и подтвердите действие.

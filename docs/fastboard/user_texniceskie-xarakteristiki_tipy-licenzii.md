# Типы лицензий | Документация Fastboard

Source: https://help.fastboard.online/user/texniceskie-xarakteristiki/tipy-licenzii/

Роль пользователя, использующего лицензию Разработчика может быть как Администратор, так и Разработчик. Роль пользователя, использующего лицензию Аналитика, может быть как Аналитик, так и Зритель.


| **Роль** | **Описание** | **Лицензия** | **Описание** |
| --- | --- | --- | --- |
| Администратор системы | Слот на человека в лицензии, может быть админом или разработчиком | Разработчик | Администратор системы имеет: все привилегии разработчика доступ в панель администратора доступ ко всем существующим проектам, группам проектов, группам пользователей, источникам данных Может управлять тенантами, с оздавать/удалять тенанты , добавлять/исключать пользователей в любой тенант Может создавать, изменять и удалять группы пользователей и д обавлять их Может редактировать пользователей, в т.ч. устанавливать новые пароли. По умолчанию у этой роли **установлены все возможные права доступа**максимального уровня |
| Разработчик | Слот на человека в лицензии с полным доступом к функционалу системы, кроме контроля и администрирования. | Разработчик | Эта лицензия предназначена для разработчиков, которым необходим **полный доступ к платформе** для создания и управления BI-приложениями: загрузка данных из источников создание и управление моделями данных редактор загрузки и SQL редактор визуализаций настройка обновлений по расписанию расчет показателей визуализация панелей создание многостраничных отчетов разработка цветовых палитр и тем. Разработчик обладает всеми теми же правами, что и **Аналитик**. Для Разработчика **закрыта** только Панель администратора. |
| Администратор организации* |  | Разработчик | Этот тип лицензииограниченная версия роли "Администратор системы", присваивается, если у администратораесть**хотябыодноограничение**вправахдоступа. Администратор организации можетназначать другим пользователям **только 4 роли** из доступного набора — назначение роли «Администратор системы» запрещено У каждого пользователя с ролью «Администратор организации»* может быть **индивидуальный набор настроек доступов** |
| Администратор тенанта | Слот на человека в лицензии, с правами администратора в рамках выделенного тенанта, позволяет управлять пользователями и самим тенантом. | Разработчик | Этот тип лицензии предоставляет доступ к тем же возможностям аналогичные правам администратора, но **строго в пределах выделенного тенанта**. ****Администратор тенанта может: создавать, удалять и переименовывать тенант управлять пользователями в рамках своего тенанта создавать пользователей, назначать пользователям роли **не выше** роли «Администратор тенанта». По умолчанию у этой роли установлены все возможные права доступа максимального уровня, в рамках администриуемого тенанта. |
| Аналитик | Слот на человека в лицензии, может быть аналитиком или зрителем | Аналитик | Этот тип лицензии предоставляет доступ **к большинству** функций платформы, включая: виртуальные данные полный доступ к созданию, настройке и удалению всех элементов отчёта, включая его страницы, визуализации, фильтры и оформление, но в рамках того набора данных, который подключен к этому проекту создавать, редактировать, копировать, перемещать и удалять как свои потоки и проекты, так и те, к которым ему предоставлен доступ Эта лицензия предназначена для **проектирования интерактивных отчётов без возможности настраивать источники данных** . |
| Зритель / Бизнес-пользователь | Слот на человека в лицензии, может быть аналитиком или зрителем | Аналитик | Этот тип лицензии предоставляет доступ **только на просмотр** информационных панелей и отчетов, созданных разработчиками и аналитиками. Эта лицензия предназначена для конечных пользователей, которым требуется только просмотр и взаимодействие с BI-контентом. В рамках проекта Зритель может использовать фильтрацию и переходы взаимодействовать с настроенными визуализации оставлять к ним комментарии |

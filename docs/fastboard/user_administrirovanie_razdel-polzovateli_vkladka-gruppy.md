# Пользователь: вкладка «Группы» | Документация Fastboard

Source: https://help.fastboard.online/user/administrirovanie/razdel-polzovateli/vkladka-gruppy/

На этой странице администратор управляет доступами пользователя к группам системы. Таблица содержит все группы в которые добавлен текущей пользователь. На этой странице администратору доступны следующие действия:

- Просмотреть все группы пользователя.
- Добавить пользователя в другие группы. Через кнопку «Добавить» и выбор одной или нескольких групп в открывшемся всплывающем окне.
- Удалить пользователя из групп. Через кнопку «Корзинка» в строке конкретной групп.

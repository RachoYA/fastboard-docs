# Создание подключения по REST API | Документация Fastboard

Source: https://help.fastboard.online/user/dispetcer-dannyx/istocniki-dannyx/podkliucenie-po-rest-api/

**REST API** — это способ взаимодействия между программами через HTTP-запросы, позволяющий получать и отправлять данные между клиентом и сервером. В отличие от «обычного» API, REST строится на стандартных HTTP-методах (у нас это GET и POST) и работает с ресурсами по URL, что делает его более универсальным и простым в интеграции.

В этой инструкции мы разберём, как настроить подключение к REST API в диспетчере данных — от заполнения базовых полей (название, URL, метод запроса) до настройки параметров авторизации, заголовков, тела запроса и других опций.

**Название источника**:

- введите имя для вашего подключения (обязательно для заполнения);
- используйте только латинские буквы, цифры и спецсимволы: `* / . - = _ < > ^ % & ! ? @ ' " : ; #`.
- если используете другие символы — появится ошибка: «Поле содержит некорректные символы».
**URL** (обязательно для заполнения):

- укажите URL-адрес API, к которому хотите подключиться;
- проверьте корректность URL перед продолжением.
**Выберите метод запроса**:

- **GET** — используется для получения информации от сервера (например, просмотр веб-страницы или получение данных из API);
- **POST** — используется для создания нового ресурса на сервере (передаёт данные для создания ресурса)

## **Сохраните подключение**[​](#сохраните-подключение)

Если вы хотите отменить настройку и вернуться к выбору типа подключения — нажмите кнопку **«Назад»**. Введённые параметры не сохранятся.

Нажмите кнопку **«Создать»**:

- система проверит заполненность полей «Название подключения» и «URL»;

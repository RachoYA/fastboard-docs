# Создать проект | Документация Fastboard

Source: https://help.fastboard.online/user/rabota-s-proektami/sozdanie-i-upravlenie-proektami/sozdat-proekt/

На этой странице вы создадите новый проект в черновиках Fastboard и подготовите его к работе с данными и публикации.

Предусловия: у вас есть роль, позволяющая создавать проекты (Администратор, Разработчик или Аналитик), и открыт менеджер проектов.


## **Создание шаблона в черновиках**[​](#создание-шаблона-в-черновиках)

Проект создается **только в черновиках**, они уникальны для каждого пользователя, никто не может видеть ваши черновики, также как и вы не можете видеть чьи-либо. Это позволяет избежать путаницы и "бардака", когда разные пользователи могут видеть и редактировать проекты под общей учетной записью.

### **Начало работы**[​](#начало-работы)

Для создания нового проекта нажмите на кнопку **«+ Создать новый проект»**. Введите название вашего проекта. Учтите, что название должно быть уникальным. Если вы попытаетесь использовать уже существующее имя возникнет **конфликт имён**. Система не позволяет создать два файла с идентичными именами, а при попытке сделать это появится предупреждение в красной рамочке о том, что такой проект уже существует.

## Ожидаемый результат[​](#ожидаемый-результат)

Проект создан в черновиках, имеет уникальное название, открывается в конструкторе и готов к дальнейшей настройке визуалов и подключению данных.

### **Сохранение проекта**[​](#сохранение-проекта)

Для завершения создания проекта его не обязательно сохранять, он в любом случае будет в черновиках. При этом, необходимо сохранять все изменения в проекте при работе с ним, для этого нажмите кнопку **«Сохранить»**.

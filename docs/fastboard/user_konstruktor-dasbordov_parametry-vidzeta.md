### **Модель данных**[​](#модель-данных)

Позволяет выбрать одну из моделей данных, ранее созданных в конструкторе моделей данных. Данные из этой модели будут использоваться для данного визуального компонента (построение графика, заполнение полей таблицы, получение значений для фильтрации и т.д.). Все визуальные компоненты использующие одну модель будут связаны через нее, то есть будут фильтровать эту модель и реагировать на ее фильтрацию. Такой подход будет полезен, если требуется отделить или изолировать какие-то данные используя общее хранилище.

### **Показатели**[​](#показатели)

Как и для разрезов в показателях **поля таблиц** выбираются из импортированных данных. Но в случае с показателями необходимо обязательно указать **агрегацию**:

- Типовые: сумма/количество/среднее/мин/макс
- По выражению: необходимо написать собственную функцию агрегации в виде SQL-запроса
**Виртуальные данные** для всех показателей генерируются автоматически.

**Пользовательское название** для показателя указывается также как и для разреза в специальном поле ввода в ячейке показателя.

**Цвет или цвета** для показателя можно выбрать по клику на фигуру круга рядом с полем ввода названия.

Интерфейс редактора кода включает **переключатель «Свободный режим»** (по умолчанию выключен), который меняет режим работы: в раздельном режиме область редактирования разделена на секции с системным текстом‑шаблоном, а во свободном — представляет собой сплошное окно ввода SQL без системного текста. Слева расположена карта модели: в раздельном режиме она показывает таблицы, привязанные к текущей модели, а во свободном — все таблицы из источников проекта.

**Частные случаи для отдельных визуализаций:**

**1) Медиаблок:**

- Код, сформированный в Редакторе в режиме **"Свободный режим"** будет формировать выражения для переменных (нет разделения на разрезы и показатели).
- Для формирования переменной для визуализации всегда берётся ровно одно первое значение.
**2) Тепловая карта:**

- Выражения для разрезов подставляются по очереди в "Разрезы по X" и "Разрезы по Y":
- Первое выражение для разреза подставляется в "Разрезы по X"
- Второе выражение для разреза подставляется в "Разрезы по Y"
- Третье выражение для разреза подставляется снова в "Разрезы по X"
- Далее продолжается чередование через 1
**3) Таблица:**

- Выражения для разрезов всегда подставляются в "Разрезы в колонках"
**4) SVG:**

- Согласно логике подстановки данных из Редактора Кода формируется не более 1 разреза, остальные игнорируются
**5) Диаграмма Ганта:**

- Если алиас выражения для разреза полностью совпадает с названием параметра, то это выражение подставляется в "Параметры", иначе в "Задачи"
**6) Визуализации с фиксированным числом показателей** (Круговая, тепловая, водопад, пузырьковая, Санкей):

- Согласно логике подстановки данных из Редактора Кода формируется не более показателей, чем доступно в визуализации (остальные игнорируются):
- Для круговой, тепловой и Санкей – не более 1
- Для водопада и пузырьковой – не более 2

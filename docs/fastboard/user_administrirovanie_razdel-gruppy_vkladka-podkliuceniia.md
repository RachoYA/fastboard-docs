# Группа: вкладка «Подключения» | Документация Fastboard

Source: https://help.fastboard.online/user/administrirovanie/razdel-gruppy/vkladka-podkliuceniia/

Панель "Подключения" в разделе Администрирование предназначена для управления внешними источниками данных, которые использованы в проектах.

Обратите внимание, что создание новых подключений невозможно непосредственно из этой вкладки. Для подготовки нового коннектора вам необходимо перейти в диспетчер данных.

## **Права Доступа**[​](#права-доступа)

Существует два вида прав доступа: **Использование** и **Управление**.

![Существует два вида прав доступа: Использование и Управление .](https://book.winsolutions.ru/uploads/images/gallery/2025-12/embedded-image-nww1khmt.png)

> **Со скриншота** ([изображение](https://book.winsolutions.ru/uploads/images/gallery/2025-12/embedded-image-nww1khmt.png)):
> Изменение прав доступа  
> Группа/пользователь  
> e.marakhin  
> Права  
> Управление  
> Использование  
> Управление  
> Скриншот показывает окно изменения прав доступа для пользователя e.marakhin в BI-платформе Fastboard, где отображаются доступные уровни прав: «Управление», «Использование» и снова «Управление».


Имея права на **Управление** вы можете:

- Видеть коннектор в общем списке
- Использовать подключение в своих проектах
- Изменять данные этого подключения
- Предоставить доступ другому пользователю
- Удалить подключение
Авторы новых подключений автоматически получают права на управление ими. Автор может открыть или закрыть доступ к подключению для других пользователей.

Имея права на **Использование** вы можете

- Видеть коннектор в общем списке
- Использовать коннектор только в своих проектах
Пользователь с ролью «Администратор» всегда имеет права на управление любым коннектором. Всегда видит все коннекторы и может ими распоряжаться.

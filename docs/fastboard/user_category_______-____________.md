# Управление пользователями | Документация Fastboard

Source: https://help.fastboard.online/user/category/раздел-пользователи


## 📄️ Пользователь: вкладка «Данные»

Вкладка для управления карточкой пользователя в разделе администрирования Fastboard: создание учетной записи, изменение роли и пароля, выдача лицензии и удаление.


## 📄️ Пользователь: вкладка «Черновики»

Вкладка в разделе пользователя для работы с его черновыми проектами в админ-панели Fastboard: просмотр, перенос, копирование и другие действия с проектами.


## 📄️ Пользователь: вкладка «Подключения»

Вкладка для выдачи пользователю доступа к подключениям и изменения прав в Fastboard, включая просмотр наследованных доступов, полученных через группы.


## 📄️ Пользователь: вкладка «Потоки»

Вкладка администрирования доступов пользователя к потокам Fastboard: назначение прав, редактирование существующих разрешений и удаление доступа к выбранным потокам.


## 📄️ Пользователь: вкладка «Группы»

Вкладка администрирования для управления членством пользователя в группах Fastboard: просмотр текущих групп, добавление в новые и удаление из выбранных групп.


## 📄️ Пользователь: вкладка «Тенанты»

Вкладка для распределения пользователя по тенантам в админ-панели Fastboard: добавление в организации, назначение лицензий тенанта и сохранение изменений.

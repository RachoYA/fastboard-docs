# Управление потоками | Документация Fastboard

Source: https://help.fastboard.online/user/category/раздел-потоки


## 📄️ Поток: вкладка «Доступ»

Вкладка для управления доступом к выбранному потоку в Fastboard: выдача прав пользователям и группам, изменение разрешений и удаление доступа.


## 📄️ Поток: вкладка «Проекты»

Вкладка потока в админ-панели Fastboard для работы с проектами: навигация по потокам, поиск и сортировка карточек, а также операции над проектами.

# Пользователь: вкладка «Потоки» | Документация Fastboard

Source: https://help.fastboard.online/user/administrirovanie/razdel-polzovateli/vkladka-potoki/

На этой странице администратор управляет доступами пользователя к потокам системы. Таблица содержит все доступы текущего пользователя к потокам. На этой странице администратору доступны следующие действия:

- Просмотреть все потоки пользователя с правами доступа.
- Добавить новые доступы к потокам данному пользователю. Через кнопку «Добавить» и выбор одного или нескольких потоков в открывшемся всплывающем окне.
- Изменить права доступа к имеющимся потокам. Через кнопку «Карандаш» в строке конкретного потока.
- Удалить доступ данного пользователя к потокам. Через кнопку «Корзинка» в строке конкретного потока.
- Если пользователь имеет доступ к потоку в составе группы, то поскольку права и сам доступ определен на уровне этой группы на странице пользователя мы можем только увидеть их наличие. А отредактировать только на странице самой группы.

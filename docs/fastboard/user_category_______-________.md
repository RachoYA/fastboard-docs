# Лицензии и активация | Документация Fastboard

Source: https://help.fastboard.online/user/category/раздел-лицензии


## 📄️ Страница «Лицензии» в админ-панели

Руководство по странице лицензий в администрировании Fastboard: активация ключа, контроль квот, выдача и отзыв лицензий, а также смена ролей пользователей.


## 📄️ Лицензионный ключ Fastboard

Описание лицензионного ключа в администрировании Fastboard: атрибуты, первичная активация, замена ключа и правила распределения лицензий между ролями пользователей.

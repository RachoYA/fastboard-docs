# 1.10.0 | Багфикс | 31.10.2025 | Документация Fastboard

Source: https://help.fastboard.online/user/roadmap/v1100-bagfiks/


## **Общий список исправлений и улучшений:**[​](#общий-список-исправлений-и-улучшений)

- В тепловой карте скорректирован порядок отрисовки элементов.
- Новая версия проекта теперь создаётся только при сохранении, а не при каждом входе.
- Добавлена всплывающая подсказка при выборе триггеров в настройках визуализаций.
- Добавлены настройки кастомизации (донастройки) приближения в визуализациях.
- Добавлена опция прокрутки данных внутри визуализаций.
- Добавлено центрирование таблиц в рабочей области при входе в модель данных.
- Устаранено появление Undefined (не определено) при загрузке данных в дашборд (отчёт).
- Исправлена работа фильтрации по выражению, которая ломалась при использовании названий таблиц.
- Исправлено некорректное имя листа при загрузке файлов.
- Устранена ошибка Unauthorized (не авторизован) при авторизации.
- SQL-запросы (запросы на структурированном языке) в визуализации теперь сохраняются корректно и отображают ошибки при некорректном синтаксисе.
- В фильтрах добавлены названия листов, на которых они расположены.
- Скрипты загрузки теперь сохраняются только по запросу, что предотвращает случайную перезапись.
- Теперь при копировании визуализаций с триггерами список используемых триггеров сохраняется.
- Исправлено отображение расписания обновлений.
- Добавлена поддержка SQL-функции (функции на структурированном языке запросов) countUnique в сводных таблицах.
- Устранена ошибка при открытии проектов в Firefox.
- Исправлена ошибка с изменением цвета фона разрезов в колонках таблиц.
- Ускорена загрузка данных в некоторых сценариях.
- Добавлена возможность закрытия всплывающих предупреждений крестиком.
- Теперь при копировании страницы в списке визуализаций отображаются все объекты на странице.
- Исправлено обновление счетчика уведомлений на карточке проекта.
- Исправлена ошибка при удалении связей в модели данных.
- Теперь корректно работает запрет на множественные связи к одному полю.
- Исправлена проблема, при которой список фильтров отображал удаленные элементы.

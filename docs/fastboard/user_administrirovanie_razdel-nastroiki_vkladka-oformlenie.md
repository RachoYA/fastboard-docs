# Настройки: вкладка «Оформление» | Документация Fastboard

Source: https://help.fastboard.online/user/administrirovanie/razdel-nastroiki/vkladka-oformlenie/

Эта вкладка предназначена для настройки шрифтов. Здесь вы можете задать шрифт по умолчанию, выбрав его из предложенного списка или загрузить свой собственный.


## **Шрифт по умолчанию**[​](#шрифт-по-умолчанию)

Вы можете задать определённый шрифт, который будет использоваться по умолчанию в ваших проектах. Откройте выпадающий список нажав на стрелочку ![Шрифт по умолчанию](https://book.winsolutions.ru/uploads/images/gallery/2025-12/embedded-image-y7dmjs3n.png) и выберите искомый шрифт.

### **Шрифты в системе**[​](#шрифты-в-системе)

Здесь представлены все существующие шрифты в системе. Также, вы можете загружать и использовать по умолчанию свой шрифт.

- Загружаемые шрифты должны быть в **формате web-font: ttf** или **woff**.
- Объем каждого файла не должен превышать **25 МБ**.
- Избыточное количество шрифтов в системе может негативно сказаться на скорости работы визуального интерфейса. Рекомендуем ограничиться загрузкой **не более пяти шрифтов**.
![Избыточное количество шрифтов в системе может негативно сказаться на скорости работы визуального](https://book.winsolutions.ru/uploads/images/gallery/2025-12/embedded-image-cmufarwg.png)

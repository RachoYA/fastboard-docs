# Роли пользователей Fastboard | Документация Fastboard

Source: https://help.fastboard.online/user/administrirovanie/spravocnye-materialy/roli-polzovatelia/

Ролевая модель Fastboard обеспечивает многоуровневое разграничение доступа, где каждая роль определяет, что пользователь может видеть и делать в системе. Для каждого типа лицензии устанавливается максимальный набор прав, которые могут быть выданы на потоки, проекты и источники данных, при этом состав этих прав является **настраиваемым**. Каждому пользователю при [создании](https://help.fastboard.online/user/administrirovanie/razdel-polzovateli/vkladka-dannye/)обязательно присваивается роль, определяющая его уровень возможностей.

Возможности каждой роли описаны в этой таблице :


| **Роль** | **Описание** | **Лицензия** | **Описание** |
| --- | --- | --- | --- |
| Администратор системы | Полный доступ ко всей функциональности. Доступ ко всем потокам, проектам и черновикам других пользователей. Управление пользователями, лицензиями и Панелью администратора. | Разработчик | Администратор системы имеет: Доступ к панели администратора Создание, изменение, удаление тенантов Перемещение объектов***** между тенантами Видит все объекты системы Видит все объекты в рамках своего тенанта Видит объекты, к которым открыт доступ администратором/владельцем Создание, изменение, удаление потока (здесь и далее – при наличии видимости объекта) Создание, изменение, удаление проекта Редактирование доступных проектов Создание копии проекта в потоке Перезапись проекта в потоке Изменение проекта в потоке Удаление проекта из потока Защита своего проекта от изменений Защита любого проекта от изменений Экспорт/импорт проекта Создание автодокументации по проекту Публикация проекта Создание источника данных Редактирование скрипта загрузки Удаление любого источника данных Удаление доступного источника данных По умолчанию у этой роли **установлены все возможные права доступа** максимального уровня ****** объекты – любые сущности в системе (потоки, проекты, пользователи, подключения и т.д.)* |
| Администратор тенанта | Слот на человека в лицензии, с правами администратора в рамках выделенного тенанта, позволяет управлять пользователями и самим тенантом. | Разработчик | Этот тип лицензии предоставляет доступ к тем же возможностям аналогичные правам администратора, но **строго в пределах выделенного тенанта**. Администратор тенанта может: Доступ к панели администратора Видит все объекты в рамках своего тенанта Видит объекты, к которым открыт доступ администратором/владельцем Создание, изменение, удаление потока (здесь и далее – при наличии видимости объекта) Создание, изменение, удаление проекта Редактирование доступных проектов Создание копии проекта в потоке Перезапись проекта в потоке Изменение проекта в потоке Удаление проекта из потока Защита своего проекта от изменений Защита любого проекта от изменений Экспорт/импорт проекта Создание автодокументации по проекту Создание источника данных Редактирование скрипта загрузки Удаление доступного источника данных По умолчанию у этой роли установлены **все возможные права** доступа максимального уровня, **в рамках администриуемого тенанта.** |
| Разработчик | Все права Аналитика плюс создание, редактирование и удаление источников данных, к которым предоставлен доступ. Формирует скрипты загрузки и модель данных. Нет доступа к Панели администратора. | Разработчик | Эта лицензия предназначена для разработчиков, которым необходим **полный доступ к платформе** для создания и управления BI-приложениями: Видит объекты, к которым открыт доступ администратором/владельцем Создание, изменение, удаление потока (здесь и далее – при наличии видимости объекта) Создание, изменение, удаление проекта Редактирование доступных проектов Создание копии проекта в потоке Перезапись проекта в потоке Изменение проекта в потоке Удаление проекта из потока Защита своего проекта от изменений Экспорт/импорт проекта Создание автодокументации по проекту Создание источника данных Редактирование скрипта загрузки Удаление доступного источника данных Разработчик обладает всеми теми же правами, что и **Аналитик**. Для Разработчика **закрыта** только Панель администратора. |
| Аналитик | Создание, редактирование, копирование, перемещение и удаление собственных потоков и проектов, а также тех, к которым предоставлен доступ. Нет доступа к Диспетчеру данных и Панели администратора. | Аналитик | Этот тип лицензии предоставляет доступ **к большинству** функций платформы, включая: Видит объекты, к которым открыт доступ администратором/владельцем Создание, изменение, удаление потока (здесь и далее – при наличии видимости объекта) Создание, изменение, удаление проекта Редактирование доступных проектов Создание копии проекта в потоке Перезапись проекта в потоке Изменение проекта в потоке Удаление проекта из потока Защита своего проекта от изменений Экспорт/импорт проекта Эта лицензия предназначена для **проектирования интерактивных отчётов без возможности настраивать источники данных** . |
| Зритель/Бизнес-пользователь | Просмотр проектов в разрешённых потоках. Нет черновиков, нет создания и редактирования. Доступна фильтрация, навигационные переходы и комментарии к визуализациям. | Аналитик | Этот тип лицензии предоставляет доступ **только на просмотр** информационных панелей и отчетов, созданных разработчиками и аналитиками. Эта лицензия предназначена для конечных пользователей, которым требуется только просмотр и взаимодействие с BI-контентом. В рамках проекта Зритель: Видит объекты, к которым открыт доступ администратором/владельцем использовать фильтрацию и переходы взаимодействовать с настроенными визуализации оставлять к ним комментарии |

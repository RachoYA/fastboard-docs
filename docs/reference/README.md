# Справочник настроек виджетов

Свойства виджетов Fastboard, собранные по реальным проектам: раздел настроек, название свойства, тип, допустимые значения и путь в JSON. Того, что здесь есть, в публичной справке нет — поэтому файлы индексируются в отдельную коллекцию `widget_settings` и подмешиваются к ответам консультанта.

Обновление:

```bash
python scripts/import_widget_settings.py путь/к/WIDGET-SETTINGS-TABLE.md
python scripts/scrape_and_index.py            # переиндексация
```

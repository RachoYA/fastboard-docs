# Специальные типы данных | ClickHouse Docs

Source: https://clickhouse.com/docs/ru/sql-reference/data-types/special-data-types

Значения особых типов данных не могут быть сериализованы для сохранения в таблице или вывода в результатах запроса, но могут использоваться как промежуточные результаты во время выполнения запроса.

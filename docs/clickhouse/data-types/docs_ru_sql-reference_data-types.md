# Типы данных в ClickHouse | ClickHouse Docs

Source: https://clickhouse.com/docs/ru/sql-reference/data-types

В этом разделе описываются типы данных, поддерживаемые ClickHouse, напримерцелые числа,числа с плавающей запятойистроки.

Системная таблицаsystem.data_type_familiesсодержит
обзор всех доступных типов данных.
Она также показывает, является ли тип данных псевдонимом другого типа данных и чувствительно ли его имя к регистру (например,boolв отличие отBOOL).

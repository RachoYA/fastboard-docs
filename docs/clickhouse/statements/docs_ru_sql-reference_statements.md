# Операторы SQL в ClickHouse | ClickHouse Docs

Source: https://clickhouse.com/docs/ru/sql-reference/statements

Пользователи взаимодействуют с ClickHouse с помощью операторов SQL. ClickHouse поддерживает распространённые операторы SQL, такие какSELECTиCREATE, а также специализированные операторы, такие какKILLиOPTIMIZE.

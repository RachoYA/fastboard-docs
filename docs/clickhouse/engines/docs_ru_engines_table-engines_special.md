# Специальные движки таблиц | ClickHouse Docs

Source: https://clickhouse.com/docs/ru/engines/table-engines/special

Существует три основные категории движков таблиц:

- Семейство движков MergeTreeдля основного использования в продакшене.
- Семейство движков Logдля небольших временных данных.
- Движки таблиц для интеграций.
Оставшиеся движки уникальны по своему назначению и пока не объединены в семейства, поэтому они отнесены к этой «специальной» категории.
